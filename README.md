# DriveGlow Car Care

DriveGlow Car Care is a modern and responsive car detailing website built with Next.js and Tailwind CSS.

The project was created as a portfolio project to showcase frontend development skills, responsive design, reusable UI sections, and modern web styling.

## Live Demo

(https://driveglow-car-care.vercel.app/)

## Features

- Responsive design for mobile, tablet, and desktop
- Sticky navigation bar
- Mobile and tablet hamburger menu
- Hero section with call-to-action buttons
- About section
- Car detailing services
- Service packages
- Why Choose Us section
- Image gallery
- Contact section
- Hover effects and interactive cards
- Responsive image layouts

## Services Included

- Exterior Detailing
- Interior Detailing
- Ceramic Coating
- Paint Correction

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
